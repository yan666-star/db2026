## 二、Python Wire v3 客户端库

### 新建文件：`SQL测试/performance_test/wire_client.py`

完整实现赛题**附件 A《RMDB Wire Protocol》**规定的客户端协议栈：

| 组件 | 功能 |
|---|---|
| `WireClient` | TCP 连接 + 8字节握手（发送 RMDB/3.0 → 验证回显），所有多字节整数大端序 |
| `read_exact()` / `write_all()` | 循环 I/O，正确处理 TCP 分片、EINTR、EOF、短读/短写 |
| `read_frame()` / `write_frame()` | 8 字节 frame header（u32 payload_len + u8 tag + u8 flags + u16 reserved）+ payload |
| `encode_cell()` / `decode_cell()` | INT32（4字节大端有符号）、FLOAT32（IEEE-754 binary32 位模式）、CHAR（4字节长度 + 原始字节） |
| `execute_stream(sql)` | EXEC_STREAM 请求：META → ROW* → RESULT_END / COMMAND_OK / TRANSACTION_ABORT / ERROR |
| `prepare_set(statements)` | PREPARE_SET 请求：原子字典安装，返回 PREPARE_OK schema |
| `execute_batch(ops)` | EXEC_BATCH 请求：typed bind 参数，AUTO_ABORT 语义 |
| `WireSqlClient` | 向后兼容适配器，提供与旧 `SqlClient` 相同的 `connect()/close()/execute()` 接口 |

### 关键协议约束（对照赛题附件 A）

- Payload 上限 1 MiB，诊断字符串上限 64 KiB
- FLOAT32 使用 `struct.pack('>I', bits)` 传输原始位模式，不经十进制文本
- CHAR 发送逻辑字符串长度 + 原始字节，无 NUL，无定长 padding
- `present` 字段：0 = NULL, 1 = 有值
- 握手不合法时关闭连接

## 四、本地测试流程

### 1. 编译

```bash
cd D:\DMS-DESIGN\db2026\.worktrees\finals-wire-ssi
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
```

验证：`build/bin/rmdb` 存在，11 个单元测试通过 `ctest --test-dir build`

### 2. 快速回归（~2 分钟）

```bash
bash SQL测试/performance_test/run_local_evaluation.sh quick
```

执行顺序：编译 → C++ 单元测试 → SQL 烟雾测试 → ACID(SI) → ACID(SER) → TPC-C quick 基准

### 3. 完整测试（对标决赛）

```bash
CLIENTS=32 bash SQL测试/performance_test/run_local_evaluation.sh full
```

包含崩溃恢复测试、完整 3 轮测量窗口、在线一致性校验。

### 4. 单脚本运行

```bash
# 仅 ACID 测试
python3 SQL测试/performance_test/run_acid_tests.py \
    --start-server --isolation serializable --crash-check

# 仅基准测试
python3 SQL测试/performance_test/run_benchmark.py \
    --start-server --setup --quick

# 仅一致性检查（需要服务端已运行）
python3 SQL测试/performance_test/check_consistency.py

# 交互式 Wire v3 客户端
./build/bin/rmdb_client -h 127.0.0.1 -p 8765
```
